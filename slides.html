1. Opening — The Problem

What happens when a developer knows a website has accessibility problems?

Today's tools tell you what is wrong.
Missing alt text. Missing form labels. Low contrast. Broken hierarchy.

The Gap: The tool points at the error, but the developer is left to manually research, write, and test every single fix.
2. Our Idea

Automated Accessibility Remediation

Detect → Fix → Verify

We're not building just another accessibility scanner.
We're building the layer between detecting a problem and actually fixing it.

3. How It Works — Hybrid Approach

Algorithms for Deterministic Logic.
AI for Contextual Interpretation.

⚙️ Deterministic Formulas

Don't use an LLM where math or AST rules give 100% precision:

  • Color Contrast: Relative luminance math ($4.5:1$).
  • Heading Hierarchy: Sequential outline tree rebalance.
  • Form Labels: Synthesizing explicit <label for="...">.
🧠 AI / LLM Interpretation

Where semantic context and human perception are required:

  • Image Alt Text: Inferred from page hierarchy, filename semantics, and surrounding text.
  • Contextual Description: Understands that "shoe.jpg" under "Shoes" means "Red running shoe".
4. The Most Important Part

The Verification Loop

What if the AI makes a mistake? We do not blindly trust the AI.
We re-scan the modified source code with our detection engine:

✅
Verified

Second pass confirms the violation was completely eliminated.

⚠️
Needs Review

Flagged if ambiguity remains or a secondary issue occurs.
